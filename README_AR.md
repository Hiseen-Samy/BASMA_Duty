# 📍 نظام تحديد وتثبيت موقع البصمة والدوام (BASMA Duty)

واجهة تفاعلية حديثة وسكربت متكامل لتحديد وتثبيت الموقع الجغرافي المعتمد للبصمة والدوام، معتمدة على خريطة **OpenStreetMap** بدقة عالية وتصميم عصري احترافي يدعم الوضعين الليلي والنهاري.

---

## ✨ المميزات الرئيسية

1. **خريطة OpenStreetMap التفاعلية**:
   - تبدأ تلقائياً عند الإحداثيات المحددة `(30.54182, 29.80293)` بمستوى تكبير 8.
   - إمكانية النقر في أي مكان على الخريطة لتحديد الموقع فوراً.
   - دبوس راداري نابض مع إمكانية السحب والإفلات بحرية (`Drag & Drop`).
   - خيارات متعددة لطبقات الخريطة: (شوارع OpenStreetMap، صور أقمار صناعية Satellite، الوضع الليلي الفاخر، تضاريس).

2. **نطاق سماح البصمة (Geofence Radius)**:
   - دائرة تفاعلية ملونة على الخريطة توضح النطاق الجغرافي المسموح به للبصمة.
   - منزلق تحكم سلس يبدأ من 30 متراً وحتى 2000 متر مع خيارات سريعة (50م، 150م، 300م، 500م، 1 كم).

3. **بحث فوري ذكي (Search & Autocomplete)**:
   - شريط بحث عائم للبحث عن أي مدينة، شارع، شركة، أو معلم في مصر والعالم مع قائمة نتائج منسدلة وانتقال سلس ومتحرك للموقع.

4. **تحديد العنوان التلقائي (Reverse Geocoding)**:
   - تحويل الإحداثيات تلقائياً إلى عنوان عربي مقروء ومفصل عبر محرك OpenStreetMap Nominatim.

5. **زر تحديد موقعك الفعلي (GPS)**:
   - استشعار موقع جهازك الحقيقي عبر المتصفح والانتقال إليه بنقرة واحدة.

6. **أدوات التصدير والربط السريع**:
   - 📋 **نسخ الإحداثيات**: نسخ `(Latitude, Longitude)` بنقرة واحدة.
   - 🗺️ **خرائط Google**: فتح الموقع مباشرة على Google Maps للمعاينة والتوجيه.
   - 🧭 **خرائط OpenStreetMap**: فتح الموقع في موقع OpenStreetMap الرسمي.
   - 🐍 **كود بايثون**: توليد كود بايثون جاهز للنسخ لاستخدامه في أي سكربت آخر.
   - 📥 **ملف GPX**: تنزيل ملف Waypoint لاستخدامه في برامج محاكاة الـ GPS (Mock Location).
   - 📄 **صيغة JSON**: تصدير كائن JSON متكامل.

7. **قائمة المقرات المحفوظة والمفضلة (Presets)**:
   - حفظ مواقع متعددة (مثل: المقر الرئيسي، الفروع المختلفة، المنزل) والتنقل بينها بنقرة واحدة.

8. **تخزين دائم ومتزامن**:
   - عند النقر على **"حفظ كموقعي الحالي"** يتم حفظ الموقع فوراً في:
     - `location.json`
     - `.env`
     - ذاكرة المتصفح `localStorage`

## 🚀 طريقة التشغيل

### الطريقة الأولى: بنقرة واحدة (ويندوز)
قم بالنقر المزدوج على ملف:
```text
run.bat
```

### الطريقة الثانية: من سطر الأوامر (Terminal)
```bash
python main.py
```
> سيقوم السكربت بتشغيل الخادم المحلي وفتح الواجهة تلقائياً في نافذة مستقلة أو في متصفحك الافتراضي على الرابط: `http://127.0.0.1:8000`

خيارات إضافية:
```bash
# الفتح مباشرة في المتصفح الافتراضي:
python main.py --browser

# تحديد منفذ مختلف:
python main.py --port 8080
```

## 🐍 كيفية استخدام الموقع في سكربتاتك الأخرى

يمكنك استيراد بيانات الموقع الجغرافي المحدد في أي سكربت بايثون داخل المشروع بكل سهولة عبر ملف `location_service.py`:

```python
import location_service

# قراءة الموقع المعتمد حالياً
loc = location_service.get_current_location()

latitude = loc["lat"]
longitude = loc["lon"]
radius = loc["radius"]
address = loc["address"]

print(f"الموقع المعتمد للبصمة: {latitude}, {longitude} (نطاق: {radius} متر)")
```

أو تجربة السكربت التوضيحي المرفق:
```bash
python example_duty_check.py
```
